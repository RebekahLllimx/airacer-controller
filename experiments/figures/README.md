# Curated Experiment Figures

This directory contains figures used to explain durable results: full-run trajectories, speed profiles, contact locations, perception overlays, and version comparisons. Bulk overlays and raw frame sequences remain outside Git.

Folder names retain the associated run identifier so a figure can be matched to `experiments/runs.csv`. The consolidated [experiment report](../report.md) provides the narrative and interpretation that previously lived in per-folder caption files.
